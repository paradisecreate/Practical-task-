16. T3.MEDIUM CORRECTION
------------------------
A significant configuration discrepancy was identified late in the review.

The working `terraform-automation` branch had:

  instance_type = "t3.micro"

However, the desired final `main` configuration should use:

  t3.medium

The user explicitly raised concern that this difference had initially been
missed.

As a result, the final configuration was changed so that:
- EC2 uses `var.instance_type`;
- the default value is `t3.medium`;
- allowed values may include `t3.micro`, `t3.small`, and `t3.medium`.

This reinforced the decision to review the complete `terraform plan` before
running `terraform apply`.
